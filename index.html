iPhone 安装与更新
第一次安装已有旧版，要更新我用 Sideloadly

用 AltStore Classic 安装到 iPhone

先看 iPhone 上有没有一个叫 AltStore 的 App。已经有、也能打开的话，直接从「添加更新源」开始。

手机里还没有 AltStore，怎么装？
  1. 在电脑上打开下方对应的官方图文教程，下载 AltServer。AltServer 装在电脑上，AltStore Classic 装在 iPhone 上。
    我用 Mac我用 Windows
  2. 打开电脑上的 AltServer，用数据线连接 iPhone，解锁手机。如果手机问「要信任此电脑吗？」，点「信任」并输入锁屏密码。
  3. 在 Mac 屏幕顶部菜单栏，或 Windows 右下角任务栏，点 AltServer 图标。点 Install AltStore，选自己的 iPhone，按提示输入自己的 Apple 账户。
  4. 等手机主屏幕出现 AltStore 图标，点开它。如果提示「未受信任的开发者」，到「设置 → 通用 → VPN 与设备管理」，点自己的 Apple 账户并信任。如果系统提示开启「开发者模式」，到「设置 → 隐私与安全性 → 开发者模式」，按提示重启并确认。
  5. 能打开 AltStore、看到底部标签栏，就装好了。电脑上的 AltServer 保持运行，数据线先留着。回到 iPhone，继续下面的步骤。

添加更新源，再安装傻瓜翻译

  1. 用 iPhone 的 Safari 打开本页。如果朋友从聊天软件发来链接，可以长按链接复制，再粘贴到 Safari 地址栏。
  2. 点下面的绿色按钮。如果手机问是否在 AltStore 中打开，点「打开」。
    添加更新源
  3. 手机会跳到 AltStore。核对源名称是「傻瓜翻译」，点 Add Source（添加源） 并确认。底部「Sources（来源）」里能看到「傻瓜翻译」，这一步就完成了。
  4. 回到 Safari，点 在 AltStore 中查看傻瓜翻译。也可以在 AltStore 底部点「Browse（浏览）」，找到「傻瓜翻译」并点进去。
  5. 在应用详情页点 FREE（免费） 或安装按钮。如果 AltStore 提示登录，使用刚才安装 AltStore 时的 Apple 账户。等进度走完，在 iPhone 主屏幕点「傻瓜翻译」，看到翻译界面就装好了。
点「添加更新源」没反应？手动添加
  1. 先确认手机上能单独打开 AltStore Classic。回到 Safari，长按下面的链接，选「拷贝链接」。如果点开后看到一页英文和括号，返回上一页再长按即可。https://abgrund233-stack.github.io/foolish-translation-ios-updates/source.json
  2. 打开 AltStore，点底部「Sources（来源）」，再点「＋」。在地址框里长按，选「粘贴」，然后点「Add Source（添加源）」。
  3. 看到「傻瓜翻译」已出现在来源列表后，回到上面的第 4 步安装。如果提示这个源已经添加，也可以直接从第 4 步继续。

已经用 AltStore 装过，怎么更新？

  1. 打开电脑上的 AltServer，让电脑保持唤醒。最简单的是用数据线连上 iPhone，再解锁手机。已经开启 Wi-Fi 同步的，可以让手机和电脑连同一个 Wi-Fi。
  2. 在 iPhone 打开 AltStore → My Apps（我的 App），查看可用更新。找到「傻瓜翻译」，点旁边的 Update（更新）。更新源只需添加一次。
  3. 等进度走完，打开傻瓜翻译即可。想确认版本，可以在 AltStore 查看已装版本，与本页顶部的版本号对照。
只看到「Refresh All」，或提示找不到 AltServer？

「Refresh All（全部刷新）」是给已装的 App 续签。要装新版，请先对照版本号。如果版本较旧，打开「Sources → 傻瓜翻译」，确认能看到新版，再回「My Apps」查看更新。

如果提示找不到 AltServer，先用数据线连接，解锁手机并打开电脑上的 AltServer。在 Mac 的「访达」或 Windows 的 iTunes 里看到这台 iPhone 后，再回手机点更新。查看官方故障排查图解

用 Sideloadly 在电脑上安装或更新

  1. 在电脑上打开本页。如果还没有 Sideloadly，先从 Sideloadly 官网 下载对应的 Mac 或 Windows 版，安装并打开。
  2. 用数据线连接 iPhone，解锁手机。如果弹出「信任此电脑」，点「信任」。在电脑的 Sideloadly 窗口中选中自己的 iPhone。
  3. 点下面的按钮，浏览器询问时选「打开 Sideloadly」。如果没有反应，就点「下载最新 IPA」，把下载好的 FoolishTranslation.ipa 文件拖进 Sideloadly 的 IPA 区域。
    用 Sideloadly 安装最新版下载最新 IPA
  4. 在「Apple ID」里填自己的 Apple 账户。如果是更新，请保留手机上的旧版，用上次的 Apple 账户和相同的 Bundle ID（包名）设置覆盖安装。
  5. 点 Start（开始），按电脑提示完成验证。等窗口显示 Done（完成），再到手机主屏幕打开傻瓜翻译。以后有新版，回到这个链接重复第 2 至 5 步。
